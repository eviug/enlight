Understanding Partition Schemes, BIOS, and Windows Installation

A Beginner's Guide by Enlight Vocational Institute

Computers are an essential part of modern education and business. Whether you are repairing a computer, replacing a hard drive, or installing a fresh operating system, understanding partition schemes and BIOS settings is a fundamental ICT skill. This guide explains these concepts in a simple and practical manner.

What is BIOS?

BIOS (Basic Input/Output System) is firmware stored on a computer's motherboard. It is the first software that runs when a computer is powered on.

Its responsibilities include:

  • Checking hardware components.
  • Detecting storage devices and peripherals.
  • Starting the boot process.
  • Loading the operating system.
Modern computers mainly use UEFI (Unified Extensible Firmware Interface), which is faster, more secure, and supports modern storage devices.

BIOS vs UEFI

BIOS UEFI
Older technology Modern replacement
Uses MBR disks Uses GPT disks
Supports up to 2TB boot disks Supports drives larger than 2TB
Slower startup Faster startup
Limited security Supports Secure Boot

What is a Partition Scheme?

A partition scheme determines how information is organized on a storage device such as a hard drive or SSD. The two most common partition styles are:

  • MBR (Master Boot Record)
  • GPT (GUID Partition Table)

Master Boot Record (MBR)

MBR is the traditional partition style used on older computers.

Advantages

  • Compatible with older BIOS systems.
  • Works with older versions of Windows.

Limitations

  • Maximum disk size of 2TB.
  • Supports only four primary partitions.
  • Stores partition information in only one location.

GUID Partition Table (GPT)

GPT is the modern partition style designed for UEFI systems.

Advantages

  • Supports drives larger than 2TB.
  • Allows many more partitions.
  • Stores multiple copies of partition data for reliability.
  • Required for many Windows 11 installations.

Limitation

  • Requires UEFI to boot Windows.

MBR vs GPT Comparison

Feature MBR GPT
Maximum Disk Size 2TB Over 2TB
Maximum Partitions 4 Primary Up to 128
Boot Mode Legacy BIOS UEFI
Reliability Lower Higher
Recommended Today No Yes

Which Partition Scheme Should You Choose?

Choose MBR if:

  • Your computer uses Legacy BIOS.
  • You are installing an older operating system.
  • Your hard drive is less than 2TB.

Choose GPT if:

  • Your computer supports UEFI.
  • You are installing Windows 10 or Windows 11.
  • Your drive is larger than 2TB.
  • You want better reliability and security.

Preparing for Windows Installation

Before beginning the installation, ensure you have:

  • A bootable Windows USB drive.
  • The Windows installation files.
  • A computer that meets the system requirements.
  • A backup of important files.
  • Correct BIOS or UEFI settings.

Changing the Boot Order

  1. Insert the Windows USB drive.
  2. Restart the computer.
  3. Press the BIOS key (F2, F10, F12, DEL or ESC).
  4. Open Boot Settings.
  5. Set the USB drive as the first boot device.
  6. Save changes and restart.

Installing Windows Step by Step

Step 1: Boot from the USB

Start the computer using the Windows installation USB.

Step 2: Select Language

  • Language
  • Time & Currency
  • Keyboard Layout

Click Next.

Step 3: Install Windows

Click Install Now.

Step 4: Enter Product Key

Enter your Windows product key or choose I don't have a product key if appropriate.

Step 5: Select Windows Edition

  • Windows 10 Home
  • Windows 10 Pro
  • Windows 11 Home
  • Windows 11 Pro

Step 6: Accept the License Agreement

Read and accept the Microsoft License Terms.

Step 7: Choose Installation Type

Select:

Custom: Install Windows Only (Advanced)

Step 8: Partition the Drive

  • Delete old partitions if no longer needed.
  • Select Unallocated Space.
  • Click New.
  • Allow Windows to create required partitions.
  • Select the primary partition.
  • Click Next.

Step 9: Windows Installation

Windows will copy files, install features, install updates, and restart several times. Do not remove the USB drive until the installation is complete.

Step 10: Initial Setup

  • Select your region.
  • Choose keyboard layout.
  • Connect to a network.
  • Create a user account.
  • Create a password.
  • Configure privacy settings.

After Installing Windows

  • Install device drivers.
  • Run Windows Update.
  • Activate Windows.
  • Install antivirus software.
  • Install essential applications.
  • Restore your files.

Common Installation Problems

Windows Cannot Be Installed to This Disk

This usually happens because the partition style does not match the boot mode.

  • UEFI → GPT
  • Legacy BIOS → MBR

Computer Will Not Boot from USB

  • Incorrect boot order.
  • Secure Boot settings.
  • USB not created correctly.

Hard Drive Not Detected

  • Loose cables.
  • Faulty storage device.
  • Missing storage controller drivers.

Missing Drivers

Download and install the latest drivers from your computer or motherboard manufacturer.

Best Practice: Always back up important files before reinstalling Windows, use GPT with UEFI whenever possible, install Windows updates immediately, and use genuine Windows installation media.
